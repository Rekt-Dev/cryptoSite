# CryptoSt8 v1

First-generation cryptocurrency market dashboard. Built entirely with React without AI assistance — raw self-taught frontend development covering live price feeds, portfolio tracking, and market overview.

> This is v1. See [cryptoSt8-v2](https://github.com/Rekt-Dev/cryptoSt8-v2) for the modernized rebuild with a cleaner architecture and expanded feature set.

## Features

- Live cryptocurrency price data
- Portfolio value tracking
- Market cap and volume overview
- Dark mode UI

## Tech Stack

- React
- CoinGecko API
- CSS Modules

## Getting Started

```bash
npm install
npm start
```
